# Валідація customerData

### Загальний опис логіки валідації <a href="#zagalnii-opis-logiki-validaciyi" id="zagalnii-opis-logiki-validaciyi"></a>

Масив `customerData` формується під час натискання кнопки «Оплатити» (коли передається POST-параметр `alliancepay_action = create_order`). Дані клієнта витягуються з глобального масиву параметрів шлюзу WHMCS `$params['clientdetails']`.

Потім сформований масив передається до DTO об'єкта SDK: `OrderRequestDTO::fromArray($orderData)`.

> **⚠️ Особливість для розробників (Валідація в SDK):** Оскільки очищення та перевірка правил валідації (`max_len`, `pattern`, `stop_words`) відбуваються всередині зовнішнього PHP SDK, цей шлюз WHMCS передає дані «як є» (as-is), попередньо трансформувавши лише телефон та код країни. Якщо SDK DTO викидає виняток (Exception) через невалідні дані, WHMCS перехоплює його, логує помилку через `logModuleCall` і виводить загальне повідомлення для користувача.
