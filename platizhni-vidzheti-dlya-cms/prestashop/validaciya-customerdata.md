# Валідація customerData

Під час створення разового платежу або оформлення підписки модуль формує `customerData` із профілю покупця, адреси доставки замовлення та контексту магазину. Заповнювати об’єкт вручну в налаштуваннях AlliancePay не потрібно.

### Обов’язкове поле

`senderCustomerId` — ідентифікатор покупця PrestaShop довжиною до 255 символів. Якщо значення порожнє або не проходить перевірку, модуль зупиняє підготовку запиту. Для підписки покупець має увійти до облікового запису.

### Додаткові поля

У версії 1.4.0 валідатор модуля вилучає порожні або некоректні додаткові поля з `customerData`. Вимоги форми оформлення замовлення в самому магазині налаштовуються окремо.

| Поле                                                       | Джерело та перевірка                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `senderEmail`                                              | Email із профілю. До 256 символів, коректний формат адреси.                                                                                                                                                                                                                |
| `senderPhone`                                              | Телефон із адреси доставки. Модуль бере `phone`, а за відсутності значення у джерелі (`null`) — `phone_mobile`. До 20 цифр поспіль. Знак «+», пробіли або дефіси не проходять перевірку.                                                                                   |
| `senderFirstName`, `senderLastName`                        | Ім’я та прізвище, до 30 символів кожне. На початку та в кінці — літера або цифра. Усередині також допускаються пробіл, дефіс і прямий апостроф. Значення лише з цифр відхиляється. Для імені додатково перевіряються службові значення на кшталт `UNKNOWN` і `CARDHOLDER`. |
| `senderMiddleName`                                         | Валідатор підтримує по батькові за правилами довжини й набору символів для імені. Стандартний модуль PrestaShop не заповнює це поле.                                                                                                                                       |
| `senderBirthday`                                           | Дата народження з профілю зареєстрованого покупця, яку модуль приводить до формату `дд.мм.рррр`. Значення `0000-00-00` пропускається.                                                                                                                                      |
| `senderCountry`                                            | Числовий ISO-код країни з контексту магазину, до 3 символів.                                                                                                                                                                                                               |
| `senderRegion`, `senderCity`                               | Область та місто з адреси доставки, до 255 і 25 символів відповідно.                                                                                                                                                                                                       |
| `senderStreet`, `senderAdditionalAddress`, `senderZipCode` | Перший рядок адреси — до 35 символів, другий — до 255, поштовий індекс — до 50.                                                                                                                                                                                            |
| `senderIp`                                                 | IP-адреса покупця в контексті запиту. Модуль перевіряє формат IPv4 або IPv6.                                                                                                                                                                                               |
| `senderGender`                                             | Формується на підставі профілю покупця. Можливі значення — `Male`, `Female`, `Other`.                                                                                                                                                                                      |

Якщо платіж не створено через `senderCustomerId`, перевірте зв’язок замовлення з покупцем у PrestaShop. Якщо в запиті відсутнє додаткове поле, звірте його вихідне значення в профілі або адресі доставки з правилами вище.
