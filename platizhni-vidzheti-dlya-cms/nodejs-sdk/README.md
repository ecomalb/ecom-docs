# NodeJS SDK

Офіційний NodeJS SDK для інтеграції з платіжним сервісом **AlliancePay**. Єдина точка входу — клас `AllianceBankClient`. Ця інструкція описує реліз **v1.5.0** і пакет `@alliance-bank/payment-sdk`.

### Можливості

* JWS-авторизація та підписування серверних запитів.
* Створення HPP-замовлень: PURCHASE, A2A та PREAUTH.
* Платежі у UAH, USD і EUR; A2A — лише в UAH.
* Завершення PREAUTH через COMPLETION.
* Повні та часткові повернення, зокрема перерахунок валютної суми у UAH.
* Перевірка стану замовлення й обробка callback.
* Створення та оновлення планів підписок, замовлення підписки та обробка її повідомлень.

### Порядок підключення

1. Встановіть пакет і перевірте технічні вимоги.
2. Налаштуйте merchantId, базову адресу API, JWS-ключ і kid.
3. Підключіть створення замовлення та збереження ідентифікаторів.
4. Налаштуйте перевірений callback і звірку стану через API.
5. За потреби додайте PREAUTH/COMPLETION, повернення та підписки.

У прикладах поля описано таблицями «Поле / Тип / Опис». Обов’язковість та автоматично заповнювані значення зазначено в описі кожного поля. Клієнт і приватний ключ використовуються на сервері.
