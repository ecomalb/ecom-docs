# Перевірка стану замовлення

Використайте `hppOrderId`, який SDK повернув при створенні замовлення. Серверний запит повертає загальний статус та історію операцій. Це дозволяє звірити результат, якщо callback затримався або відповідь на попередній запит втрачено.

```php
use AlliancePay\Sdk\Payment\Order\CheckOrderData;

$order = (new CheckOrderData())->checkOrderData($hppOrderId, $authDto);
$status = $order->getOrderStatus();
$operations = $order->getOperations();
```

#### Поля відповіді `OrderDataResponseDTO`

| Поле          | Тип      | Опис                                                                                                                              |
| ------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `hppOrderId`  | `string` | Ідентифікатор замовлення в банку. Зіставте `getHppOrderId()` зі значенням, збереженим під час створення замовлення.               |
| `merchantId`  | `string` | Перевірте за `getMerchantId()`, що відповідь стосується вашого мерчанта.                                                          |
| `orderStatus` | `string` | Поточний стан усього замовлення. Отримайте його через `getOrderStatus()`.                                                         |
| `operations`  | `array`  | Історія операцій замовлення. Через `getOperations()` знайдіть оплату, резервування, списання або повернення, яке перевіряєте.     |
| `coinAmount`  | `int`    | Сума з відповіді банку в мінімальних одиницях. Отримайте її через `getCoinAmount()` і звірте суму та валюту з обліком замовлення. |

Для оновлення обліку перевірте результат саме потрібної операції. Якщо статус проміжний або запит завершився помилкою, залиште замовлення в очікуванні звірки.
