# Валідація customerData

Модуль формує `customerData` під час підготовки замовлення. Метод `prepareCustomerData` бере дані з профілю покупця та платіжної адреси замовлення, а сервіс `CustomerDataValidator` перевіряє їх перед передаванням у банк.

### Обов’язковий ідентифікатор

`senderCustomerId` — ідентифікатор покупця, який модуль визначає для замовлення. Максимальна довжина — 255 символів. Якщо значення порожнє або не проходить перевірку, Magento зупиняє підготовку запиту з помилкою `LocalizedException`.

### Додаткові поля

| Поле                               | Джерело в Magento та правила перевірки                                                                                                                                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `senderFirstName`                  | Ім’я з профілю покупця або з платіжної адреси гостя. До 30 символів. Допускаються літери, цифри, дефіс та апостроф. Спеціальні символи по краях і значення лише з цифр відхиляються. Також відхиляються службові значення NULL, 3D SECURE, SURNAME, CARDHOLDER та UNKNOWN у наведеному регістрі. |
| `senderLastName, senderMiddleName` | Прізвище та по батькові з профілю або платіжної адреси гостя. До 30 символів кожне. Застосовуються ті самі обмеження на символи, що й для імені. Перелік службових значень застосовується лише до senderFirstName.                                                                               |
| `senderBirthday`                   | Дата народження з профілю зареєстрованого покупця. Модуль приводить її до формату дд.мм.рррр і перевіряє дату. Для гостьового замовлення профілю немає.                                                                                                                                          |
| `senderEmail`                      | Email із платіжної адреси, до 256 символів. Формат перевіряє валідатор електронних адрес Magento.                                                                                                                                                                                                |
| `senderPhone`                      | Телефон із платіжної адреси, до 20 цифр поспіль. Знак «+», пробіли, дужки та дефіси не проходять перевірку.                                                                                                                                                                                      |
| `senderCountry`                    | Дволітерний код країни з платіжної адреси модуль перетворює на числовий код ISO 3166, до 3 символів.                                                                                                                                                                                             |
| `senderRegion, senderCity`         | Область і місто з платіжної адреси. Область — до 255 символів, місто — до 25.                                                                                                                                                                                                                    |
| `senderStreet`                     | Перший рядок вулиці з платіжної адреси, до 35 символів.                                                                                                                                                                                                                                          |
| `senderAdditionalAddress`          | Валідатор підтримує значення до 255 символів. Стандартний модуль залишає поле порожнім і вилучає його з даних запиту.                                                                                                                                                                            |
| `senderZipCode`                    | Поштовий індекс із платіжної адреси, до 50 символів.                                                                                                                                                                                                                                             |
| `senderIp`                         | IP-адреса покупця, яку визначає модуль. Формат перевіряє валідатор IP-адрес Magento.                                                                                                                                                                                                             |
