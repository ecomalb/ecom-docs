# Скасування підписки

Після скасування:

* Усі заплановані (майбутні) платежі цієї підписки будуть анульовані
* Вже проведені платежі залишаться без змін

#### **Вхідні параметри:**

| **Параметр** | **Опис**    | **Формат даних** | **Обовʼязковість** | **Приклад**              |
| ------------ | ----------- | ---------------- | ------------------ | ------------------------ |
| hppOrderId   | Id підписки | string           | так                | 1697008393082nW0c1jr6KVv |

#### **Вихідні параметри:**

| **Параметр** | **Опис**        | **Формат даних** | **Приклад**              |
| ------------ | --------------- | ---------------- | ------------------------ |
| hppOrderId   | Id підписки     | string           | 1697008393082nW0c1jr6KVv |
| orderStatus  | статус підписки | string           | CANCELED                 |

#### **Приклад запиту**

```json
{
   "hppOrderId":"{{hppOrderId}}"
}
```

#### **Приклад відповіді**

```json
{
    "hppOrderId":"{{hppOrderId}}",
    "orderStatus": "CANCELED"
}
```
