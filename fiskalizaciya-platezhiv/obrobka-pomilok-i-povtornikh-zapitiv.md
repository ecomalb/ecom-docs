# Обробка помилок і повторних запитів

Статус FAIL означає, що поточний запит на фіскалізацію завершився помилкою. Він не означає, що платіжну операцію більше не можна фіскалізувати.&#x20;

Перевірте `errorCode` і `errorDescription`, усуньте причину помилки та надішліть запит повторно. Синхронна відповідь зі статусом PENDING підтверджує прийняття повторного запиту до опрацювання. Після цього дочекайтеся результату через Callback.

Наприклад, у прикладі відповіді API для акцизного товару без УКТЗЕД повертається код `b_bucket_excise_product_without_classification_code_error`.

Перед повторним надсиланням запиту після технічної помилки перевірте його результат і врахуйте правила повторної обробки, щоб уникнути дублювання фіскальних чеків.
