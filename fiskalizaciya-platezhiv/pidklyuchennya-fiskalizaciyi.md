# Підключення фіскалізації

Для використання фіскалізації виконайте попереднє налаштування:

1. У [Кабінеті мерчанта AlliancePay](https://merchant.alb.ua/home) відкрийте розділ **«Основні налаштування» → «Фіскалізація»**.
2. Підключіть Alliance Kasa за інструкціями в інтерфейсі. Якщо ви ще не зареєстровані в Alliance Kasa, пройдіть реєстрацію в цьому сервісі.
3. Переконайтеся, що всі обов'язкові об'єкти в Alliance Kasa зареєстровані та доступні для використання.

Якщо торгова точка й каса вже зареєстровані в ДПС, можна використовувати наявні об'єкти.

Після успішного підключення мерчант отримує можливість надсилати запити на фіскалізацію підтримуваних платіжних операцій через API AlliancePay.
